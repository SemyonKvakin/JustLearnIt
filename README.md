# JustLearnIt - Языковая школа

Веб-сайт языковой школы для изучения иностранных языков.

## Описание проекта

JustLearnIt - это современная платформа для записи на языковые курсы и занятия с репетиторами.

## Функционал

### Главная страница
- Описание языковой школы и её преимуществ
- Список доступных курсов с пагинацией (по 3 курса на странице)
- Поиск курсов по названию и уровню
- Таблица репетиторов с возможностью фильтрации
- Карта учебных ресурсов (Яндекс.Карты)
- Форма оформления заявок на курсы и занятия с репетиторами

### Личный кабинет
- Просмотр списка заявок с пагинацией (по 5 заявок на странице)
- Подробная информация о каждой заявке
- Редактирование заявок
- Удаление заявок

## Технологии

- **HTML5** - структура страниц
- **CSS3** - стилизация
- **Bootstrap 5.3** - адаптивная вёрстка и компоненты
- **JavaScript (ES6+)** - логика и взаимодействие с API
- **Fetch API** - AJAX запросы
- **Яндекс.Карты API** - интерактивная карта ресурсов

## API

Проект использует REST API для работы с данными:
- Базовый URL: `http://exam-api-courses.std-900.ist.mospolytech.ru/api`
- Эндпоинты:
  - `/courses` - список курсов
  - `/tutors` - список репетиторов
  - `/orders` - работа с заявками (CRUD операции)

## Особенности реализации

### Расчёт стоимости курсов

Стоимость рассчитывается по формуле:
```
Общая стоимость = ((courseFeePerHour × durationInHours × isWeekendOrHoliday) + 
                   morningSurcharge + eveningSurcharge) × studentsNumber
```

С учётом автоматических скидок и надбавок:
- Ранняя регистрация (30+ дней): -10%
- Групповая запись (5+ человек): -15%
- Интенсивный курс (5+ часов/неделю): +20%

### Дополнительные опции
- Дополнительные учебные материалы: +2000 руб. за студента
- Индивидуальные занятия: +1500 руб. за неделю
- Культурные экскурсии: +25%
- Оценка уровня владения языком: +300 руб.
- Интерактивная онлайн-платформа: +50%
